# coles-trend.user.js
A userscript for the Coles Trend Chrome Plugin which allows to support it in **Safari iOS/iPadOS/MacOS** using any userscript manager extension.

> The use of UserScript is to be able to run the script in the Safari mobile browser too.

<img height="424" alt="demo" src="https://github.com/user-attachments/assets/14f31c33-4c1d-4f67-9b9b-418aeb57778d" />

> *This userscript is based on the source code at the [Coles Trend Chrome extension](https://chromewebstore.google.com/detail/coles-trend/ehgelgeppdkecdonfeefokbnicmjpbdd), and historical data is supplied by the "Data Holdings Group".*

# Instructions
1. Install the open-source Safari userscript manager from [here](https://github.com/quoid/userscripts#installation:~:text=14.1%20or%20higher.-,App%20Store%20Link,-Development%20Progress).
2. Download the Coles Trend userscript from this repo at [here](https://github.com/physicslog/coles-trend.user.js/raw/refs/heads/main/coles-trend.user.js)
3. To sync this userscript across all your Apple devices, create a folder in iCloud Drive and paste the userscript there. Then link this folder to the userscript manager.

Done!
